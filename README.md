# Amazon India Sales Dashboard

## Data Science Internship Project

This project presents an Amazon India Sales Dashboard designed to analyze sales, profit, orders, products, customer order status, payment methods, fulfillment methods, and geographic performance.

### Key Analysis
- Overall Sales & Profit Performance
- Monthly Sales & Profit Trends
- Category-wise Sales, Profit & Units Sold
- Top 10 Products by Sales
- Order Status Analysis
- Returns & Cancellations
- Payment Method Performance
- Fulfillment Performance
- State-wise Sales, Profit & Orders

### Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Data Visualization
- Data Analysis
